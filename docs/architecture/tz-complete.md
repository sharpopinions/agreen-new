## Сторінки і функціонал

### 1. Головна сторінка (/)

**Блоки:**
- Слайдер 2-3 слайди + блок партнерства з CTA "Стати партнером"
- Карусель брендів + "Дивитись усі бренди"
- Популярні категорії — 6 карток (2 ряди по 3) + "Дивитись каталог"
- Каталог товарів — таби (Популярні / Рекомендовані / Акційні / Передзамовлення), 4-5 карток у ряд
- Статуси товарів: "Немає в наявності / В дорозі / Очікується"
- Послуги — 3-4 картки + "Дивитись всі послуги"
- Партнерство — блок для Виробників / Дилерів / Оптовиків
- Про компанію — цифри (6000+ товарів, офіційний дистриб'ютор, тех. підтримка)
- Блог — 4 останні статті + "Дивитись усі новини"
- SEO-текст

**Phase:** 6 (частково) → 9 (реальні дані) → 17 (блог блок)

---

### 2. Каталог — загальна сторінка (/catalog)

- Хлібні крихти: Головна → Каталог
- Інтро-текст + поле пошуку
- Плитка категорій (3-4 у ряді) з фото/іконками
- Популярні бренди (карусель)
- Акційні пропозиції / Хіти продажів (карусель)
- SEO-текст

**Phase:** 9

---

### 3. Категорія/підкатегорія (/catalog/{slug})

- Хлібні крихти: Головна → Каталог → Категорія → Підкатегорія
- H1 = назва категорії

**Лівий сайдбар (фільтри):**
- Ціна від/до + "Очистити всі фільтри"
- Дерево категорій (з чекбоксами)
- Бренди (чекбокси)
- Наявність / Передзамовлення / АКЦІЯ
- EAV атрибути (налаштовуються в адмінці per категорія)
- Адмін може приховати категорії та бренди у фільтрах

**Над товарами:**
- Кількість знайдених товарів
- Сортування: ціна, популярність, новизна, рейтинг
- Кількість на сторінці: 24, 48...
- Перемикач вигляду: плитка / список

- Пагінація + "Показати ще"
- SEO-текст для кожної категорії окремо

**Phase:** 9

---

### 4. Картка товару (/p/{slug} — короткий URL без категорій)

- Хлібні крихти з повним шляхом категорій
- H1 = назва товару
- Галерея фото
- Відео-огляд (YouTube) — прев'ю → відкривається плеєр
- **Права колонка:**
  - Бренд (посилання на сторінку бренду)
  - Артикул (SKU)
  - Статус наявності (з ERP)
  - Ціна + закреслена стара ціна
  - **Персональна ціна** для бізнес-клієнта (тільки залогінений)
  - Теги: акція / новинка / хіт
  - Кількість (з обмеженням по залишку з ERP)
  - Кнопки: "Додати в кошик", "Додати до порівняння", "Швидке замовлення" (попап)
  - Варіації (колір, розмір, комплектація)
- Опис товару (текст)
- Таблиця характеристик (EAV атрибути)
- **Попередження** (жовта іконка) — якщо потрібен супутній товар, текст з посиланням (редагується в адмінці)
- Блок "Супутні товари" (першим — обов'язковий)
- **Повідомлення про заміну:** "Товар знято з виробництва → Доступна заміна" або "Рекомендуємо новішу модель"
- "Нещодавно переглянуті товари" (карусель, показується скрізь)

**Phase:** 10

### 5. Бренди — загальна (/brands)

**Phase:** 9

### 6. Сторінка бренду (/brands/{slug})

  - **Медіабанк:** фото, відео, PDF для завантаження
- Окремий URL per вкладка + canonical на основну
- Сайдбар: "Інші бренди" (3-6 релевантних, налаштовується в адмінці)

### 7. Порівняння товарів (/comparison)

- Іконка в хедері з лічильником
- До 4 товарів (в т.ч. з різних категорій)
- Зліва — характеристики, справа — товари
- Видалити товар (іконка кошика)
- "Додати в кошик" для кожного
- Порожній стан: ілюстрація + "Перейти в каталог"

**Phase:** 10

### 8. Кошик

**Три стани:**

**Порожній кошик:**
- Ілюстрація + "Ваш кошик порожній"
- "Перейти в Каталог"
- 3 рекомендованих товари

**Попап при додаванні товару:**
- Фото, назва, артикул, кількість (змінити), вартість, видалити
- Загальна сума
- "Перейти до кошика" | "Оформити замовлення" | "Продовжити покупки"
- Блок "Супутні товари" (карусель)

**Повна сторінка (/cart):**
- Перелік товарів, кількість, ціна, видалення
- "Перейти до оформлення"

**Важливо:**
- Стандартний товар + передзамовлення → 2 окремих замовлення
- Передзамовлення — без оплати і вибору доставки

**Phase:** 13

---

### 9. Оформлення замовлення (/checkout)

- Хлібні крихти: Головна → Кошик → Оформлення
- Зліва: авторизація (зареєстрований / новий клієнт)
- Справа: товари

**Типи оплати (всі):** Картка, Онлайн оплата, Рахунок з ПДВ, Рахунок без ПДВ, Оплата кур'єру, Накладений платіж
**Типи оплати (бізнес-партнери додатково):** Відстрочка платежу

**Типи доставки:** Нова Пошта, Укрпошта, Justin, Meest Express, Самовивіз, Кур'єр

**Бізнес-клієнт:** може редагувати замовлення протягом 1 робочої години після відправки

**Phase:** 13

---

### 10. Подяка за замовлення

- Без хлібних крихт
- Галочка/персонаж
- "Дякуємо за замовлення!" + номер (#12345)
- Товар, кількість, статус "В обробці", орієнтовна доставка
- "Переглянути замовлення" (незареєстровані → email, зареєстровані → кабінет)
- "Продовжити покупки"

**Phase:** 13

---

### 11. Авторизація / Реєстрація (попап)

- Зліва: форма входу (email/телефон + пароль, "Забули пароль?", "Запам'ятати мене")
- Google, Facebook авторизація
- Справа: переваги реєстрації
- Реєстрація: Ім'я, Прізвище, Телефон, Email, Пароль, чекбокс Політики
- Email підтвердження → редирект у кабінет
- **Вибір ролі (4 картки):** Клієнт / Бізнес-клієнт / Бізнес-партнер / Ще не визначився

**Phase:** 12

### 12. Кабінет Клієнта (звичайний)

**Шапка:** Привітання (ім'я), вибір мови, пошук, кошик

**Бокове меню:**
1. Каталог
2. Мої замовлення (статуси, пошук, повторити, завантажити рахунок/чек)
3. Документообіг (чек, рахунок, підтвердження, завантажені клієнтом)
4. Умови співпраці (знижки, cashback — баланс + історія)
5. Технічна підтримка (запит консультації, сервісу, візиту; статуси)
6. Персональні дані (ім'я, email, телефон, адреса доставки)
7. Налаштування
8. Вихід

**Активація:** автоматична (без модерації)

**Phase:** 12

### 13. Кабінет Бізнес-клієнта

**Відмінності від звичайного клієнта:**
- Шапка: закріплений менеджер A-GREEN (ПІП, телефон, пошта, Telegram)
- Активація: через модерацію менеджером
- Реєстрація: + Назва компанії, ІПН/ЄДРПОУ, контактна особа, коментар, чекбокс Договору

**Розширений функціонал:**
- Замовлення: + завантаження рахунку/податкової/акту + Відстрочка платежу
- Документообіг: Контракти та доп. угоди (статуси), Рахунки/акти/накладні (архів + фільтрація + прив'язка)
- Умови співпраці: персональні знижки з ERP (умови по датах, заборона подвійних знижок)
- Навчання: запис на навчальні події, записи (відео, документи), інструкції
- Персональні дані: Назва компанії, юр тип (ФОП/ТОВ), ЄДРПОУ, кілька юр осіб (холдинг), менеджери/співробітники, кілька адрес доставки, способи оплати, статус заборгованості

**Phase:** 14

## Таблиці БД яких не вистачає в поточній схемі

Після аналізу ТЗ знайшов пропущені таблиці:

```
product_videos          ← YouTube посилання (одне або кілька per товар)
product_related         ← pivot: пов'язані/супутні товари
product_recently_viewed ← нещодавно переглянуті (user_id/session + product_id)
brand_media             ← файли медіабанку бренду (фото, відео, PDF)
brand_related           ← "Інші бренди" налаштовувані per бренд
form_submissions        ← заявки з форм (партнерство, консультація, зворотній зв'язок)
event_registrations     ← реєстрації на події блогу
vacancy_applications    ← резюме/відгуки на вакансії
analytics_settings      ← GTM, GA ID, FB Pixel per store (JSON)
cookie_categories       ← категорії cookie (необхідні, статистика, тощо)
```

Ці таблиці додамо у відповідних фазах.
