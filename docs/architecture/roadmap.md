## Заплановані фази 📋

### Phase 8 — Filament Admin
Встановлення Filament 3. Ресурси для управління каталогом:
- Мови, валюти, stock statuses
- Категорії (дерево) + переклади + SEO
- Бренди + переклади
- Бейджі
- Атрибути і значення
- Фільтри per категорія
- Товари + переклади + фото + атрибути

### Phase 9 — Каталог (фронтенд)
- /catalog — всі категорії
- /catalog/{slug} — категорія з фільтрами
- Сайдбар: ціна, бренди, EAV атрибути
- Сортування, пагінація

### Phase 10 — Сторінка товару
- Галерея фото
- Атрибути/характеристики
- Статус наявності
- Супутні товари, перегляди

### Phase 11 — MeiliSearch
- Індексація товарів і категорій
- Автопідказки в хедері
- Сторінка результатів пошуку

### Phase 12 — Авторизація + Кабінет клієнта
- Реєстрація / вхід (email, Google, Facebook)
- Вибір ролі (Клієнт / Бізнес-клієнт / Бізнес-партнер)
- Кабінет: замовлення, дані, налаштування

### Phase 13 — Кошик + Замовлення
- Кошик (попап + сторінка)
- Оформлення з вибором доставки і оплати
- Email підтвердження

### Phase 14 — Бізнес-клієнт
- Персональні ціни з ERP
- Холдинг-структура
- Документообіг (контракти, рахунки, акти)
- Відстрочка платежу

### Phase 15 — Інтеграції (ERP/CRM)
- Excel Driver (перший)
- Синхронізація цін і залишків
- Лог в Filament

### Phase 16 — Бізнес-партнер + Дропшипінг
- API Нова Пошта
- Масове замовлення через Excel
- Управління співробітниками

### Phase 17 — Контент
- Блог, Акції, Послуги, Вакансії
- Статичні сторінки

### Phase 18 — SEO + Аналітика
- Sitemap, robots.txt, JSON-LD
- Google Analytics, Facebook Pixel

### Phase 19 — SaaS
- Реєстрація магазинів
- Тарифи і білінг
- Роутинг по доменах
- Super-admin
